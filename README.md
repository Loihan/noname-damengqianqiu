# 大梦千秋扩展包

**大梦千秋** 是一个为 **无名杀** 制作的武将扩展包，收录 **26 名武将**，分包为 **三国志、山海经、魔法时代、万古仙道** 四个系列。每名武将都带有独立技能机制、专属台词与技能配音，其中相当一部分还配有自绘主题选择框、武将牌能量条、卡牌与技能骨骼特效。

本包同时维护一套自有的**概念体系**（蓄力技、战场技、昂扬技、变阶技、择令技等），游戏内「扩展 → 大梦千秋 → 📖 新概念与特点」可查看完整定义与标准写法。

- **作者**：Loihan
- **版本**：7.5
- **适配环境**：无名杀诗笺版（推荐配装：千幻聆音、十周年UI、皮肤切换）
- **说明**：本包为作者自娱自乐之作，**不承诺任何竞技平衡性**。武将强度普遍偏高，与原版平衡体系无关，请勿代入排位/竞技环境。

> **写在前面**：本包的特效、动态皮肤、视频演出依赖外部扩展。相关扩展未安装或未启用时，本包会**静默跳过**这些表现层内容，绝不报错、也不影响技能结算与游戏本体。

## 一、安装

1. 将本文件夹（`大梦千秋/`）整体放入无名杀的 `extension/` 目录；
2. 启动游戏，在「选项 → 扩展」中启用本扩展；
3. 重启一次游戏，使卡牌包与皮肤模块完成注册（控制台可见 `[大梦千秋] 扩展已加载 v7.5`）。

**目录结构**

```text
大梦千秋/
├── README.md / CHANGELOG.md / LICENSE / info.json
├── extension.js            # 核心调度：品质、分包、势力、梦前缀、AI 代入、音频劫持、卡牌与皮肤装载
├── intro.js                # 扩展介绍文案与「📖 新概念与特点」面板内容
├── skin.js                 # 皮肤与动皮注册（千幻聆音 + 十周年UI），运行期按需加载
├── character/              # 武将模块（每名武将一个文件）
│   ├── sgz_*.js            # 三国志系列（梦＊）
│   ├── shj_*.js            # 山海经系列
│   ├── mfsd_*.js           # 魔法时代系列
│   └── wgxd_*.js           # 万古仙道系列
├── ai/                     # 技能 AI 集中地（与 character/ 同名一一对应）
├── effect/                 # 表现层模块：主题选择框、能量条、卡牌特效、整理手牌、通用粒子装饰
├── card/                   # 「神武」装备牌与【集巧生烟】定义（不进牌堆，按需现场获得）
├── animation/              # 骨骼动画素材（曹髦决进、魏延壮誓/觉醒、关羽觉醒等）
├── video/                  # 梦钟会【矫诏】演出视频
├── image/                  # 武将原画、卡面、主题框 SVG 素材
├── skin/image/             # 皮肤静态图（按武将分目录）
├── audio/                  # 技能配音、阵亡配音、卡牌动作配音
└── __dytest/               # 开发期 Node 自检脚本（不影响游戏运行）
```

## 四、玩法与视觉亮点

### 概念与技能体系

本包技能统一采用自有概念写法，详细定义与标准简写见游戏内「📖 新概念与特点」。

- **持恒技**：不会被「无效技能」类效果影响的技能。本包所有武将技能均为持恒技。
- **法则技**：技能拥有者死亡后依然生效的技能，如梦关羽【魂殇】、梦钟会【逐月】。
- **蓄力技**：以「蓄力点」为资源的技能体系，描述开头标注 `蓄力技（X/Y）`。典型如梦钟会【权患】的权(4/4)/患(0/∞)、梦文鸯【惊跃】（0/0）、梦吕布【镇猎】（1/4）。配套概念「倾囊」＝移除全部蓄力点并摸等量张牌。
- **战场技**：令若干角色参战并持续循环，按「战流 / 战间 / 退战」三段式书写，如梦陆逊【韬晦】【焚灭】。
- **昂扬技**：限定技的变体，可由「昂扬」条件刷新为可再次发动，如梦吕布【噬炁】、梦曹髦【倾讨】。
- **变阶技**：拥有 0 至上限等级的技能，只生效当前等级的效果，如梦文鸯【仇决】。
- **择令技**：进入「律令 / 禁择 / 强决」流程的技能，如梦曹髦【缚渊】。
- **使命技**：梦关羽【魂殇】、梦魏延【竭伐】、梦杜预【倾势】。达成条件即觉醒并获得衍生技，失败则承受相应代价。
- **大空壳 + 子技能**：梦黄月英【绮梦】、梦孙寒华【妙剑】【莲华】、梦魏延【破扼】等技能外壳只负责展示与派生，实际结算交给多个子技能，便于分条维护与单点调试。

### 表现层

- **武将牌能量条**：梦赵云【劫烬】剑形蓄力条、梦钟会【权患】双生计量（剑身＝权 / 圆珠＝患）、梦杜预【破竹】竹节进度条、梦孙寒华【妙剑】五剑充能条、梦文鸯【霆踪】雷电进度条、梦郭嘉【窥天】星穹能量条、梦陆逊【业火残响】火条。
- **主题选择框**：梦曹髦【缚渊·帝诏】帝王诏令框、梦吕布镇猎框、梦小乔五音花色框、梦杜预三陈/谏国框、梦魏延壮誓框、梦陆逊焚灭框、梦关羽梦刃框。均为本地注入，仅对本地人类玩家生效，AI、联机与录像回放自动回退引擎默认框。
- **卡牌与技能特效**：梦马超【雷殛】电光与「破」字易伤令符、梦孙寒华【妙剑】手牌剑气卡框、梦吕布「炁」/镇猎杀卡面美化、梦关羽武圣出框、梦曹髦决进骨骼演出、梦魏延壮誓形态演出与觉醒 BGM、梦钟会【矫诏】视频演出、梦甘宁【劫营】目标的翡翠锁定光环与【夜魇】的本视角暗幕。
- **整理手牌**：点「整理手牌」时按武将定制排序——梦曹髦、梦孙寒华、梦吕布把标记牌置左；梦赵云、梦小乔按花色归组。
- **皮肤与动皮**：梦小乔「秋水伊人」、梦姜维「炽剑补天／敕剑伏波」、梦钟会「潜蛟觊天／潜蛟觊天2」、梦郭嘉「以身证道」、梦诸葛诞「寿春举义」、梦马超「迅骛惊雷」、梦关羽「血海罗刹」、梦曹髦「枭龙破渊／枭龙破渊2」、梦魏延「狂志吞天／狂志吞天2」、梦孙寒华「威灵尽显」、梦赵云四张花色皮、梦甘宁「战破无间」、梦文鸯「势若万钧」、梦黄月英「惊鸿一瞥」、梦陆逊「烈火炽天／烈焰炽魂／蛇年清明」。
- **自动换装**：梦曹髦获得【腾渊】→「枭龙破渊2」，失去后还原；梦魏延【竭伐】击杀觉醒→「狂志吞天2」；梦姜维发动【幽明】→「敕剑伏波」；梦钟会局内首次【矫诏】→「潜蛟觊天2」并播放演出视频。

### 音频

## 五、技术实现

- **模块化架构**：每名武将的逻辑、翻译、台词封装在 `character/` 下的独立文件，表现层抽取到 `effect/`，`extension.js` 只做核心调度与数据合并。
- **AI 集中管理**：AI 逻辑统一收纳到 `ai/`（与武将文件同名一一对应），角色文件里只写 `ai: AI.<技能id>`。`check_ai_centralized.mjs` 可打印 AI 覆盖率和缺口清单，并校验 AI 引用的合法性。
- **四系列分包**：通过 `characterSort` 划分为三国志／山海经／魔法时代／万古仙道，并注入各系列主题色翻译。
- **「梦」前缀系统**：以 `lib.namePrefix` 注册前缀颜色，配合 `lib.translate[角色 + "_prefix"]` 实现前缀与名字的分色显示。
- **AI 评估体系**：为武将配置威胁度（threaten）与暴露度（expose），并在关键技能上实现选敌、卖血、救援、连招等决策逻辑。
- **品质与配置**：全部武将自动设为传说品质。
- **外部扩展联动**：皮肤、动皮、骨骼特效分别对接千幻聆音、十周年UI 与皮肤切换；相关扩展缺席时逐项降级，不阻塞游戏。
- **开发期自检**：`__dytest/` 提供 30 余个 Node 脚本，可在不启动游戏的前提下校验技能辅助函数链、AI 引用、皮肤与表现层建造逻辑。
