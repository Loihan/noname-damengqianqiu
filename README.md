# 大梦千秋扩展包

**大梦千秋** 是一个为 **无名杀** 设计的武将扩展包，收录 **18 名原创/重制武将**，分为 **三国志、山海经、魔法时代、万古仙道** 四个系列。每名角色都拥有独立的技能机制、专属台词与技能配音，其中部分角色带有定制 UI 特效与卡牌音效。

- **作者**: Loihan
- **版本**: 7.2
- **环境推荐**: 无名杀诗笺版、千幻聆音扩展包
- **说明**: 本扩展包为作者的自娱自乐之作，**不承诺任何竞技平衡性**。武将强度普遍偏高，与原版游戏的平衡体系无关，请勿代入排位/竞技环境。

---

## 一、武将命名与势力体系

本包以“大梦”为线索，将三国志系列武将重新演绎为 **“梦＊”形态**，并以 **粉紫色前缀（`#cb82c2`）** 区分。

v7.2 起，三国志系列武将的势力回归史实——由早期统一的“神”势力改为各自所属的 **魏／蜀／吴／晋／群**，而山海经、魔法时代、万古仙道系列仍保持 **神** 势力。

| 系列 | 前缀/主题 | 势力 |
| --- | --- | --- |
| 三国志 | 梦＊ | 魏／蜀／吴／晋／群（另有诸葛诞专属“叛”势力） |
| 山海经 | — | 神 |
| 魔法时代 | — | 神 |
| 万古仙道 | — | 神 |

> 诸葛诞拥有独立的 **“叛”** 势力，作为其【定叛】【伐逆】【焚玉】【困诛】【孤绝】等技能的判定基础。

## 二、安装与目录结构

将解压后的文件夹（`大梦千秋/`）整体放入 `noname/extension/` 目录下，然后在游戏中启用即可。

```text
大梦千秋/
├── README.md
├── CHANGELOG.md
├── LICENSE
├── info.json
├── extension.js            # 核心调度：品质、分包、势力、梦前缀、AI 代入、音频劫持、前言注入
├── character/              # 武将模块目录（每名武将一个 JS 文件）
│   ├── sgz_*.js            # 三国志系列（梦＊）
│   ├── shj_*.js            # 山海经系列
│   ├── mfsd_*.js           # 魔法时代系列
│   └── wgxd_*.js           # 万古仙道系列
├── image/                  # 武将原画 / 品牌图 / 定制界面素材（如曹髦帝诏 UI）
└── audio/                  # 音频资源目录
    └── [武将ID/]           # 按武将分组
        ├── die/            # 阵亡配音
        ├── skill/          # 技能配音
        └── cards/          # 卡牌动作配音（音频劫持）
```

## 四、技术特性

- **模块化 ES6 架构**：每名武将的逻辑、翻译、台词与品质均封装在 `character/` 下的独立 `js` 文件中；`extension.js` 仅作为核心调度与数据合并入口，便于维护与扩展。
- **四大系列分包**：通过 `characterSort` 将武将划分为 三国志 / 山海经 / 魔法时代 / 万古仙道 四个系列，并注入各自的主题色翻译。
- **史实势力体系**：三国志武将按魏／蜀／吴／晋／群回归史实势力；诸葛诞额外拥有专属“叛”势力（`game.addGroup`，血液鲜红主题色），支持完整的势力判定链。
- **“梦”前缀系统**：通过 `lib.namePrefix` 注册前缀颜色，结合 `lib.translate[角色 + "_prefix"]` 与角色翻译名，实现“梦＊”武将的梦幻粉紫前缀展示。
- **传说品质自动设置**：所有武将自动设置为传说品质。
- **AI 评估体系**：为所有武将配置威胁度（threaten）与暴露度（expose），供 AI 决策与连招评估使用。
- **定制 UI / 动效**：包含武将牌能量条（赵云劫烬、钟会权患）、曹髦【缚渊·帝诏】帝王诏令主题选择框、马超【雷殛】电光与易伤特效等，均为本地注入、仅在确认环境生效。
- **音频劫持系统**：智能识别并替换钟会、郭嘉等武将的卡牌动作配音；同时自动注册千幻聆音台词包（台词、原画、音频路径一体化）。
- **扩展包前言注入**：在武将面板“仅点将可用”设置下方注入本包介绍语，阐述“持恒技”设计理念。
